# Разработка и внесение данных

1. Установите Go 1.27.4+, Docker Compose и (для генерации OpenAPI) `oapi-codegen` v2.
2. Правьте JSON в `data/catalog`; не редактируйте PostgreSQL вручную как источник истины.
3. Каждая запись обязана содержать постоянный ID, категорию, редакцию, источник, книгу, издателя, лицензию, версию, атрибуцию, тексты переводов и машинно-читаемые mechanics.
4. Проверки: `make validate`, `make test`, `go vet ./...`, `make generate-openapi`, Docker build.
5. В PR укажите источник, лицензии, количество записей по категории/языку, diff ID, статусы переводов, известные несовпадения с upstream. Тексты закрытых книг не принимаются без подтверждённых прав.

Механики должны хранить числа/структуру/варианты, а не только прозу. Для новых категорий добавляйте профильную JSON Schema и проверку нормализации. Нельзя менять ID при переименовании/переводе; если upstream ID изменился, храните alias/mapping, а не создавайте молча новый публичный ID.
